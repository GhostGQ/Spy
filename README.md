# Шпион 🕵️

Локальная (pass-and-play) party-игра «Шпион» на одном устройстве. Компания передаёт
телефон по кругу, каждый смотрит свою роль, затем идёт обсуждение и голосование.

## Стек

React Native (0.81) · **Expo SDK 54** · TypeScript · Expo Router · Zustand · AsyncStorage ·
NativeWind · React Native Reanimated · React Native Gesture Handler

> SDK 54 выбран для совместимости с актуальным **Expo Go**.

## Запуск

```bash
npm install        # legacy-peer-deps уже включён в .npmrc (nativewind тянет react-dom)
npx expo start     # затем: отсканируйте QR в Expo Go, или i / a / w
```

Если в песочнице/без интернета — добавьте `--offline`, чтобы expo не ходил в сеть.

### Заметка про `import.meta`

Некоторые зависимости (zustand) используют `import.meta.env` для dev-проверок. Этот
токен ломает парсинг бандла на web и в Hermes, а трансформация Expo не покрывает
node_modules. Поэтому в `babel.config.js` подключён локальный плагин
`./import-meta-plugin.js`, который заменяет `import.meta` на безопасный объект.

Проверка типов:

```bash
npx tsc --noEmit
```

## Режимы

| Режим | Слово | Спец-роль | Количество спец-ролей |
|-------|-------|-----------|------------------------|
| **Классический** | у мирных одно секретное слово | Шпион (без слова) | задаётся, мирные всегда в большинстве |
| **Хаос** | то же, что классический | Шпион (без слова) | **скрыто**, рандомится при старте (может быть > мирных) |
| **Призрак** | мирные видят слово | Призрак (видит «Мирный» + фейк-слово) | задаётся, призраков < мирных |

## Поток экранов

`Главное меню → Создание игры → Выбор категории → Выдача ролей → Выбор времени →
Таймер (пауза/выход) → Выбор победителя → Итоги`

- **Создание игры** — без скролла: режим, число игроков, число спец-ролей.
- **Выбор категории** — плиточный экран, можно выбрать **несколько** категорий; слово
  раунда берётся из одной из выбранных.
- **Выдача ролей** — почти полноэкранная карточка, переворачивается по тапу (других
  кнопок нет): тап открывает роль, повторный тап скрывает и передаёт устройство дальше.

Завершение вручную (через паузу) и по истечении таймера ведут на один и тот же экран
выбора победителя.

## Структура

```
app/                 # экраны (Expo Router, file-based)
  index.tsx          # главное меню
  rules.tsx          # правила (modal)
  settings.tsx       # настройки (modal)
  game/              # setup, categories, roles, timer-setup, timer, result, summary
src/
  store/             # gameStore (сессия), settingsStore (persist в AsyncStorage)
  game/              # types, roles (логика выдачи ролей)
  data/              # categories (слова), modes (метаданные режимов)
  components/        # PrimaryButton, Card, RoleCard, CircularTimer, Stepper, …
  theme/colors.ts    # палитра
```

## Расширение

- **Слова/категории** — добавьте объект в `src/data/categories.ts`.
- **Иллюстрация меню** — замените вектор `src/components/SpyIllustration.tsx` или положите
  свой ассет в `assets/` и используйте `<Image>`.
- **Цвета** — `tailwind.config.js` (`theme.extend.colors`) и `src/theme/colors.ts`.
